# IPA 签名器

不用自己的 Mac，用 GitHub 云上的 Mac 电脑，给 iPhone 的安装包（`.ipa` 文件）签名。

小白话：iPhone 的 app 安装包要先“盖章”才能装到手机上。苹果的盖章工具只在 Mac 上有，这里用 GitHub 免费提供的云上 Mac 电脑来盖，你在手机上点一下就能跑。

现在签的是 OpenList（Yalist）这个 app，未签名的原包来自官方发布 v2025.07.292，包名是 `com.github.openlist.openlist`。

## 现在是什么状态

- ✅ 临时签名（adhoc 模式）已经跑通过：证明“下载—解包—签名—打包—上传”整条路在云上 Mac 能跑。
- ⏳ 真签名（real 模式）还没跑过：需要你填好下面的 Secrets 才能跑。

## 两种模式

| 模式 | 要不要 Apple ID | 签完能不能装到手机上 |
| --- | --- | --- |
| adhoc（临时签名） | 不要 | 不能。苹果不认临时签名，只用来验证流程通不通 |
| real（真签名） | 不要密码，但要证书 + 描述文件（见下面） | 能装，7 天过期 |

## 真签名要填的东西（Secrets）

在仓库页面点 **Settings → Secrets and variables → Actions → New repository secret**，一个一个加：

| 名字 | 是什么 | 从哪来 |
| --- | --- | --- |
| `P12_BASE64` | 开发者证书（`.p12` 文件）转成 base64 文字 | 从 ESign 里导出证书（见下面） |
| `P12_PASSWORD` | 导出 `.p12` 时你自己设的密码 | 导出的时候现设 |
| `MOBILEPROVISION_BASE64` | 描述文件（`.mobileprovision` 文件）转成 base64 文字 | 从 ESign 里导出描述文件（见下面） |

⚠️ 证书和描述文件必须是给包名 `com.github.openlist.openlist` 建的，而且描述文件里要包含你这台手机（ESign 建描述文件时会自动把本机加进去）。

base64 转换：手机上可以用快捷指令或者在线工具把文件转成 base64 文字再粘贴；电脑上有终端的话一句命令就行：`base64 -i 证书.p12`。

## 证书和描述文件从哪来（ESign 路线，手机上就能做）

1. 手机上装 ESign，打开后用你的 Apple ID 登录（会收到苹果的双重验证短信/弹窗，照着输就行）。
2. ESign 会自动帮你向苹果申请开发者证书，并建好描述文件（“准装证”，写着这个 app 能装在哪台手机上）。
3. 在 ESign 里把证书（`.p12`）和描述文件（`.mobileprovision`）导出/分享出来，存到手机文件里。
4. 按上面的表转成 base64，填进仓库的 Secrets。

这一步只需要做一次，之后 7 天过期了再重复一次就行。

## 怎么跑一次

1. 打开仓库的 **Actions** 页面，点左边 **Sign IPA**。
2. 点 **Run workflow**，选模式：`adhoc`（只验证流程）或 `real`（真签名）。
3. 等几分钟跑完，签好的包在页面下方的 **Artifacts** 里下载，名字是 `signed-ipa-数字`。
4. 每次跑完的验证结果会写进仓库的 `docs/last-run.md`，不用进 Actions 也能看。

## 7 天过期怎么办

免费账号的描述文件只有 7 天有效，过期后 app 打不开。到期前重新跑一次 real 模式就行：ESign 里重新生成描述文件，更新 `MOBILEPROVISION_BASE64` 这个 Secret（证书一般一年才过期，不用每次都换）。

以后可以再加自动刷新：用 fastlane 的 `sigh` 命令在每次运行时自动向苹果申请新的描述文件，那就不用手动导出了（见下面“为什么不能只填 Apple ID 密码”）。

## 为什么不能只填 Apple ID 密码

苹果现在强制双重验证，光有账号密码登不上去，必须再输一次手机上收到的验证码。自动化工具没法替你收这个验证码。

业界常用的办法是 `fastlane spaceauth`：先在电脑上跑一次，手动输验证码，生成一个“会话凭证”（`FASTLANE_SESSION`），把它存进 Secrets，之后一段时间内 fastlane 就能直接用。但这个凭证过几周会失效，失效了要重新跑一次 `spaceauth`。

这个仓库第一版故意不用这套，原因：

- 只填证书 + 描述文件，不碰你的 Apple ID 密码，最省事也最安全。
- App Store Connect API 密钥（fastlane 推荐的、不用双重验证的办法）只有付费开发者账号（99 美元/年）才能开，免费账号开不了。

等你觉得手动导出太麻烦了，再加 fastlane 自动刷新那条路。

## 安全提醒

- Secrets 只有仓库主人能看到，别人看不到；代码里没有任何密码和证书。
- 证书和描述文件不要发给别人，也不要贴到公开的地方。
- 这个仓库是公开的，所以 GitHub Actions 完全免费（公开仓库不限分钟数）。

## 签好的包怎么装到手机上

从 Artifacts 下载 `.ipa` 后，用 ESign 导入安装（ESign 可以直接装已经签好名的包）。以后 Scripting 版签名服务做好了，就不用手动走这一步。

## 常见问题

**跑 real 模式报错“描述文件和包名对不上”？**
描述文件是给另一个包名建的。重新在 ESign 里给包名 `com.github.openlist.openlist` 建一个描述文件，再更新 Secret。

**跑 real 模式报错“证书和描述文件不是同一个”？**
`.p12` 和描述文件不是同一套。两个都从同一个 ESign 里导出来，别混着用。

**跑 real 模式报错“描述文件已过期”？**
重新生成描述文件，更新 `MOBILEPROVISION_BASE64`。

**adhoc 模式跑通了，包为什么装不上？**
正常。临时签名本来就装不上，它只证明流程通了。要装得跑 real 模式。
